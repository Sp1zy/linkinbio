# Responsive Link-in-Bio Landing Page

A minimal, high-efficiency single-column landing page optimized for mobile screen distributions, allowing users to navigate between multiple active repositories, professional platforms, and portfolios from one centralized location.

## 🚀 Live Demo
You can view the live deployed website here: https://sp1zy.github.io/linkinbio/

## ✨ Features
- **Mobile-First Responsive Layout:** Architected primarily for screen viewing inside mobile app web-browsers (such as Instagram or LinkedIn link previews).
- **Flexbox Centering:** Uses CSS Flexbox layout properties to ensure perfect vertical and horizontal centering of all content cards across any screen height.
- **Visual Hierarchy Styling:** The primary portfolio target button uses specialized color highlight classes to catch user attention immediately and increase conversion rates.
- **Minimalist Aesthetic:** Employs a soft gradient backdrop coupled with sharp typography boundaries to achieve a clean modern look without relying on heavy multimedia files.

## 🛠️ Tech Stack
- HTML5 (Compact profile tags)
- CSS3 (Flexbox centering alignment, UI-accent buttons, Micro-interactions)
